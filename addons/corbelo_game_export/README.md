# Corbelo Game Export, the Godot add-on

Imports packs written by [corbelo-game-export](https://github.com/kylebegeman/corbelo-game-export)
into a Godot 4 project. It does nothing besides import.

1. Copy this folder to `addons/corbelo_game_export` in the project.
2. Turn it on under Project > Project Settings > Plugins.
3. Put a pack's folder anywhere in the project, by hand or with
   `corbelo-game-export install <pack.zip | folder> --project <project>`.

What it makes next to a pack's files, and what it leaves alone, is in the README of the
package under "Godot add-on".
